# Key Highlights

- End-to-end ML platform for industrial predictive maintenance, anomaly detection, and energy optimization.
- Time-series pipeline with ingestion, preprocessing, feature engineering, and windowed model inputs.
- Multiple model outputs: failure risk, remaining useful life (RUL), and anomaly detection.
- AEOS energy deviation utilities for efficiency insights.
- FastAPI REST API with admin/viewer roles, JWT auth, and SQLite persistence.
- Plotly Dash dashboard for interactive analysis and operations.
- Demo mode with 7-day trial enforcement and licensing controls.
- Synthetic data generator for single or fleet scenarios.
- Docker and one-click Windows launch scripts for local or containerized setup.
- Reporting and fintech endpoints for cost, ROI, and system reporting.
