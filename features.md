# TerraEnergy AI Features

- Data ingestion and preprocessing for industrial time-series
- Feature engineering with windowed inputs
- Models: failure risk, RUL (remaining useful life), anomaly detection
- AEOS energy deviation utilities (single and batch)
- Decision engine for risk fusion and recommended actions
- Fintech analytics: reports, PDF export, ROI, forecast, compare, savings
- REST API (FastAPI) with bcrypt + JWT auth and role-based access
- Interactive dashboard (Plotly Dash) with training and inference panels
- SQLite persistence for users, training jobs, and dataset metadata
- EDA suite: distributions, correlations, outliers, scatter analysis
- Demo/licensing mode with 7-day enforcement and license overrides
- Synthetic data generator for single rig and fleet scenarios
- Docker + one-click launch scripts
