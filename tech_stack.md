# TerraEnergy AI Tech Stack

- Language: Python 3.10+ (3.11 slim base image in Docker)
- ML & data: NumPy, pandas, scikit-learn
- API: FastAPI + Uvicorn
- Dashboard/UI: Plotly + Dash
- Auth & security: bcrypt, PyJWT
- Persistence/ORM: SQLite + SQLAlchemy
- Config/utilities: PyYAML, python-dotenv, python-multipart, python-dateutil, pytz
- Reporting: ReportLab (PDF)
- Explainability: SHAP
- Dev/test tooling: pytest, pytest-cov, black, flake8, mypy (dev extras)
- Deployment: Docker, Docker Compose, Windows one-click scripts
